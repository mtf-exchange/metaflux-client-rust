# Security Policy

## Supported versions

Pre-1.0, only the most recent `0.x` release receives fixes.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/mtf-exchange/metaflux-client-rust/security/advisories/new)
rather than opening a public issue. We will acknowledge the report and work on
a fix before any public disclosure.
